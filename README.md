# 公的統計WebAPIの罠

**インドネシア中央統計庁（BPS）のWebAPIから州別パネルを作るまでに踏んだ、10個の罠の記録**

日本計算機統計学会 第40回シンポジウム 報告
「**検算駆動による生成AIとの協働** ── インドネシア公的統計WebAPIからの州別パネル構築とShinyによる可視化」の補足資料です。

---

## この記録は何か

インドネシアの州別統計を、33州・16年分のパネルデータに整えました。指標は11本。作業は生成AIとの協働で行い、Rのコードは25ファイル・4,507行になりました。

その過程で、**応答が正常に見えたまま誤った値を返す経路**を10個見つけました。この記録は、その10個を1本ずつ、次のように書いたものです。

- どういう投げかけ（プロンプト）をしたか
- 何が返ってきたか
- **どこで間違えかけたか**
- 何をきっかけに気づいたか
- どう直したか
- 直ったことをどう確かめたか

**うまくいった話ではなく、うまくいかなかった過程を残すこと**を目的にしています。

---

## この罠はインドネシア固有ではありません

10個のうち、少なくとも半分は**どのAPIでも起こります**。日本の e-Stat、世界銀行、OECD、Eurostat、GitHub API ── ページングを使い、多言語で、行政区画が変わり、統計の定義が年によって変わるところなら、どこでも同じことが起きます。

各記事には「**あなたのAPIでも同じことが起きる**」という節を置き、他のAPIでの具体例とチェックリストを付けました。

## 10個に共通する形

書き終えてみると、10個はほぼ同じ形をしていました。

> **エラーは出ない。行数も欠測数も正常に見える。ただ、値だけが静かに壊れる。**

そして、原因の多くは**自分が置いた条件**にありました。上限値、検索語、絞り込みの条件、既定のパラメータ。条件を置いた瞬間に「見なかった範囲」が生まれ、その範囲は出力のどこにも現れません。

だから、この記録を通じて繰り返し出てくる対処は1つです。

> **見なかった範囲の大きさを、必ず数字で確かめる。**

- 総件数と取得件数を突き合わせる
- 絞り込む前と後の両方を画面に出す
- 州別の値を合計して、公表の全国値と比べる
- 別の表から同じ量を取って、突き合わせる

### 効いた検算は4種類だった

| 検算 | 何を捕まえたか |
|---|---|
| **集計の照合**（州別の和 ＝ 公表の全国値） | 二重計上（罠05・罠09） |
| **独立系列との照合** | 公表基準の断絶（罠10） |
| **構造的制約**（合計は部分の間、州数は33/34/38） | 罠09・罠10 |
| **不変量**（1州×1年＝1行、全州が全年に出現） | 罠05・罠08 |

このうち **「独立系列との照合」がいちばん強い**、というのが結論です。他の3つは手元のデータの内部整合性しか見ません。**系全体がずれているときは、外から持ってくるしかありません。**

## 生成AIとの協働について

この作業は、対話型生成AIとの協働で行いました。そして**AIも、同じ罠を作り、同じ罠を見逃しました**。

観測されたAIの誤り方には、はっきりした特徴があります。

> **AIは、知識が足りなくて間違えるのではなく、自分が置いた前提を疑わない形で間違える。**

罠01の上限値 `max_page = 50` も、罠02の絞り込み語 `"line"` も、**AI自身が数日前・数分前に書いたもの**でした。そして、おかしな結果を見たとき、その値を疑いませんでした。

したがって、人間側の検算は「AIの知識を補うため」ではなく、「**AIの前提を外から破るため**」に必要です。これが報告の中心的な主張です。

## 読み方

**順番に読む必要はありません。** 各記事は独立して読めるように書いてあります。

ただし、いくつか続き物があります。

- **罠01 → 罠02**：罠01を直した直後に、同じ形の罠が再発した記録。順に読むと構造が見えます
- **罠03 → 罠04**：罠03で作ったデバッグ用の道具が、罠04を未然に防ぎました
- **罠05 → 罠06**：罠05で入れた期間の指定が、罠06の引き金になりました
- **罠02 → 罠10**：罠02で見つけた表を、罠10でようやく使えるようになりました

**[罠10](10-series-break.md) は最終回**で、連載10本の総括（効いた検算の4類型、AIの誤り方、人間とAIの分担）を置いてあります。急ぐ方は、[罠01](01-silent-truncation.md) と [罠10](10-series-break.md) の2本だけでも筋は通ります。

前提知識はほとんど要りません。「インターネットで検索したら結果が10件ずつ出て、下に『次へ』がある」という経験があれば読めるように書きました。コードはRですが、読み飛ばしても筋は追えます。
